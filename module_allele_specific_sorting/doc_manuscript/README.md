# Allele-specific sorting manuscript project

Overleaf-ready LaTeX working project for the supplementary methods and results of
`module_allele_specific_sorting`:

- the among-population LD ceiling set by F_ST versus realised among-population LD and within-population LD, along physical and genetic distance;
- sorted units versus F_ST-matched unsorted units (allele-specific versus haplotype-wide sorting);
- long-range (unlinked) association tails versus a chromosome-wise permutation null (BDMI predictions) — **pending**.

Neutral simulations (`../../sim_founder_fix/`, corrected and phased mosaic founders) enter only through
`../R/07_neutral_sim_contrast.R` (differentiation of near-neutral vs ancestry-informative loci; Table `neutral_sim`,
Figure `07_neutral_sim`). LD-based statistics are not compared with simulations (the neutral model overestimates
short-range within-population LD for all loci).

Compile from this folder with:

```bash
latexmk -pdf -outdir=build main.tex
```

Numerical authority: the saved outputs in `../data/`. Tables in `tables/` and figure copies in `figures/` are
generated by `../R/05_doc_tables.R` (run from the formica_hybrid repo root) — re-run it after any of
`R/02`–`R/04`, `R/06` or `R/07` changes rather than editing the tables by hand. Text marked `\pending{...}` (red) depends on
unfinished analyses.

Upload the complete `doc_manuscript` directory to Overleaf so that the relative paths remain valid.
